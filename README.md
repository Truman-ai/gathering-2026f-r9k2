# 집회 참가 접수 웹앱

참가자가 폼을 작성하면 **Google 스프레드시트에 한 줄씩 쌓이고**, 담당자는
`admin.html`(암호 보호) 또는 스프레드시트에서 현황을 봅니다.

접수 폼은 **단계형(마법사)** 입니다. 한 화면에 한 부문씩 보여주고 위아래
스크롤 없이 `이전 / 다음` 으로 이동합니다.

```
① 인트로   제목 · 일시 · 장소 · 문의 → [등록하기]
② 신청자 정보   이름 · 동반 인원(성인/청소년·어린이) → 인원 수만큼 동반자 이름 칸 자동 생성
③ 참석 일정   세션별 체크박스 + [전체 참석] 버튼
④ 식사 신청   날짜별 행으로 끼니별 인원 + [전체 인원 일괄 적용] / [초기화]
⑤ 숙박 신청   밤(숙박일)별 인원 + [전체 인원 일괄 적용] / [초기화]
⑥ 차량   이용/탑승 위치 선택
⑦ 기타 요청사항
⑧ 비용 안내   기도문 · 공통/개인 비용 · 헌금 계좌(복사 버튼) → [다음]
⑨ 입력 확인   전체 요약 → [제출하기]
⑩ 완료
```

⑧ 은 `config.js` 의 `costNotice.enabled`, ③~⑦ 단계는 각 설정에 따라 자동으로 켜지고 꺼집니다.
(STEP 번호는 인트로·비용 안내를 빼고 ②부터 1로 셉니다.)

```
집회_참가접수_웹앱/
├─ index.html          접수 폼 (참가자용)
├─ admin.html          접수 현황 (담당자용, 간단 암호)
├─ assets/
│  ├─ config.js        ★ 여기만 고치면 대부분 설정됨
│  ├─ style.css
│  ├─ app.js           폼 로직
│  └─ admin.js         현황 로직
└─ apps-script/
   └─ Code.gs          스프레드시트 저장/조회용 백엔드
```

## 1. 지금 바로 확인 (저장 없이 미리보기)

`config.js` 의 `scriptUrl` 이 비어 있으면 **미리보기 모드**로 동작합니다.
폼 모양·항목·화면만 확인할 수 있고 제출해도 저장되지 않습니다.

- 로컬에서 열기: 아래 중 하나
  - `index.html` 을 브라우저로 그냥 열기 (file://)
  - 또는 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000`

## 2. 실제로 저장되게 연결하기 (Google 스프레드시트 + Apps Script)

### 2-1. 스프레드시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트 생성 (이름 예: `2026 가을집회 접수`)
2. 주소창의 URL 을 복사해 둠 → 나중에 `config.js` 의 `sheetUrl` 에 넣으면 관리자 화면에 바로가기 생김

### 2-2. Apps Script 붙이기
1. 그 스프레드시트에서 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 지우고, 이 폴더의 `apps-script/Code.gs` 내용을 전부 붙여넣기
3. 맨 위 `var ADMIN_PASS = '1234';` 를 원하는 관리자 암호로 변경
   (이 값이 유일한 관리자 암호. 공개 소스에는 저장하지 않음)
4. 저장(💾)

### 2-3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 설정
   - 설명: 아무거나 (예: `v1`)
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**  ← 반드시 이걸로 해야 폼에서 전송됨
4. **배포** → 권한 요청이 뜨면 본인 계정으로 허용
   (“Google에서 확인하지 않은 앱” 경고 → 고급 → 이동)
5. 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/....../exec`)

### 2-4. config.js 채우기
`assets/config.js` 를 열어 수정:

```js
scriptUrl: "https://script.google.com/macros/s/....../exec",  // 2-3에서 복사한 것
sheetUrl:  "https://docs.google.com/spreadsheets/d/....../edit", // (선택) 2-1의 URL
```

> 관리자 암호는 `config.js` 에 넣지 않습니다(공개 소스에 노출되므로).
> `admin.html` 에서 입력한 값을 Apps Script 의 `ADMIN_PASS` 가 검증합니다.

이제 `index.html` 에서 접수하면 스프레드시트 `접수` 시트에 줄이 쌓이고,
`admin.html` 에서 `ADMIN_PASS` 암호를 넣으면 현황·통계·CSV 내보내기가 됩니다.

> **코드를 수정한 뒤에는** Apps Script 에서 **배포 → 배포 관리 → (연필) → 버전: 새 버전 → 배포**
> 를 해야 반영됩니다. (URL 은 그대로 유지됨)

## 3. 접수 항목 바꾸기 — `assets/config.js`

| 항목 | 키 | 설명 |
|---|---|---|
| 집회명/일시/문의 | `eventTitle` 등 | 인트로 화면에 표시 |
| 장소 | `eventPlace` / `eventPlaceAddress` / `eventPlaceMapUrl` | 이름 - 주소(파란 밑줄 링크). 주소·링크는 비워도 됨 |
| 마감 안내 문구 | `deadlineNotice` | 표시만, 실제 차단 안 함. 비우면 숨김 |
| 비용 안내 화면 | `costNotice` | 인트로 다음 안내 화면. `enabled: false` 면 건너뜀. 기도문·비용 묶음(`groups[].rows[] = {icon, label, unit, amount}`)·헌금 계좌 |
| 참석 일정 | `schedules` | 체크박스(복수 선택). `id` 는 유지, `label` 만 수정 |
| 식사 | `meals.days` | 날짜(행)별로 끼니를 묶어 인원 입력. `days` 대신 `items` 평면 목록도 가능 |
| 숙박 | `lodging.nights` | 밤(숙박일)별 인원 입력. `enabled: false` 면 단계 숨김 |
| 차량 | `transport.desc` / `transport.options` | 안내 문구 / 이용·탑승 위치 선택지 |
| 동반 인원 | `companions.askAdultChild` | 성인·어린이 나눠 받기 여부. **입력한 수만큼 ‘동반자 이름’ 칸이 자동 생성** |
| 기타 요청사항 | `showNotes` | 표시 여부 |
| 필수 입력 검증 | `validation` | `enabled:false` 면 전부 자유 입력. 개별 항목(`name`/`schedules`/`companionNames`/`meals`/`lodging`)을 `false` 로 두면 그 항목만 필수 해제. 통과 못 하면 빨간 문구 + 빈 칸 빨간 테두리, ‘다음’·제출 차단 |

일정을 하나도 안 두면 참석 일정 선택이 사라지진 않으니, 단일 집회면
`schedules` 를 한 개만 남기세요.

## 4. 관리자 화면 (`admin.html`)

- 접속 시 `ADMIN_PASS` 암호 입력 → Apps Script 가 검증 (세션 동안 유지)
- 접수 폼처럼 **단계형**. 하단 `이전 / 다음` 으로 이동, 상단 `새로고침`
  ```
  1 종합 대시보드   접수 건수 / 총 참석 인원 / 식사(끼니 계) / 숙박 신청 / 차량 운행 필요 인원
  2 참석 일정        세션별 참석 인원(신청자+동반자) + 연인원 합계
  3 식사 신청        끼니별 신청 인원 + 끼니 계 합계
  4 숙박 신청        날짜(밤)별 숙박 인원 + 연박 합계
  5 차량 운행        양평역·버스터미널 탑승 선택자 명단(신청자+동반자 이름) + 인원 합계
  6 기타 요청사항    요청사항을 남긴 신청자와 그 내용만
  7 접수 내역        일정 필터 · 이름/동반자 검색 · CSV 내보내기 · 전체 표(원본)
  ```
- 2~6 페이지는 `config.js` 의 해당 기능이 켜져 있을 때만 나타남
- **CSV 내보내기**(7페이지) 는 엑셀에서 바로 열리는 UTF-8 BOM
- 원본은 언제나 스프레드시트에서도 확인 가능

> 관리자 화면은 “간단 암호” 수준입니다. 암호(`ADMIN_PASS`)가 알려지면 명단이
> 노출되니, 담당자에게만 공유하고 추측하기 어려운 값으로 두세요.
